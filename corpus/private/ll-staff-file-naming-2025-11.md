# How the firm names files

Consistent names let anyone find a document without asking. The convention is short on purpose.

## The pattern
Start with the client short name in lowercase, then the document type, then the period, separated by hyphens. The period is year and month, written as four digits, a hyphen, and two digits.

Examples of the shape: client short name, then "bank-statement", then the period. Payroll reports use "payroll-register". Engagement letters use "engagement-letter" and the signing month.

## Rules
- Lowercase only, no spaces, no ampersands.
- Never put an account number or a tax identification number in a file name.
- Drafts end in "-draft" and are deleted when the final is filed.
- Scans are saved as PDF, never as a phone photo.

## Short names
The six client short names are redfork, soonersprout, keystone, prairiewind, bluedome and tallgrass. A new client gets a short name from the partner before any file is created.

Renaming an old file needs a note in the folder log.
